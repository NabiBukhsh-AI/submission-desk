# Demo script

Five minutes, six artefacts, no slides. Everything below runs offline against
the synthetic corpus with demo mode on, so nothing depends on a network or a
key and nothing can be sent anywhere. Rehearse it twice; the timings are for a
person who has.

## Before

    make seed          # four synthetic candidates, assessed
    make doctor        # every line should read ok or warn; no fail
    make demo          # opens the interface

Have a terminal open beside the browser. Set the browser to the **Queue** page.

## 0:00 — The one sentence

Say it before showing anything:

> The language model produces evidence. Deterministic Python produces the
> score, the band, and the recommendation.

Then, in the terminal:

    grep -hoE '"(score|band|verdict|rating|recommendation)"\s*:' \
        contracts/schemas/AssessmentResponse.json \
        contracts/schemas/CandidateProfile.json \
        contracts/schemas/CompositionResponse.json | wc -l

It prints `0`. Those three files are every schema a model is asked to fill,
exported from the code and checked in, and none has a property that could
hold a judgement. A test asserts it on every commit
(`tests/unit/test_schemas_forbid_scores.py`). Thirty seconds.

## 0:30 — A strong candidate, and where every sentence came from

Open **rin-takahashi** from the queue.

- The banner is green: nothing was found in the documents.
- The band and the derivation: every rule that fired, in sentences. Read one
  aloud.
- Expand a criterion. Each quotation has a page and a "Show me where". Click
  it. The quotation appears in its paragraph. Say: *this is not a summary. It
  is the document, and the system checked it was there before it was allowed
  to count.*
- Scroll to the excluded panel. It is empty. Say: *this is where the system
  shows what it caught itself inventing. Empty is the good case; the panel is
  never hidden.*

Ninety seconds.

## 2:00 — A candidate the system refuses to score

Open **priya-raman**.

The band says *not enough information*, and the score is absent. Say: *a
one-page CV against a nine-point rubric. The wrong answer is a low score; the
right answer is a refusal to score, and a list of what to ask.* Scroll to the
information requests: one per unresolved point, naming the point.

Forty-five seconds.

## 2:45 — The injection

Open **sam-okafor**. The banner is red.

Read the quoted sentence: an instruction to the screener, inside the CV. Point
at the cost line: zero tokens. Say: *ten deterministic detectors run before any
model call. This was caught before a model saw it, it cost nothing, and it is
shown to a person as data — quoted, not obeyed. Nothing was assessed, and this
candidate reaches a decision only through this page.*

Forty-five seconds.

## 3:30 — The reviewer corrects the system

Open **tomasz-nowak**, the borderline one. Find a criterion resolved as
*partial*. Open **Correct an assessment**, change it, and pick a reason from
the list. Say: *the reviewer never types a score. They change what a point
resolved to and say why, and the recommendation is recomputed through the same
rules — there is one scoring implementation in the repository. The reason
routes somewhere: a prompt, the rubric, or a documented limit.*

Show the preview of the new band. Do not commit it — say that approving would
record a decision attributed to a configured reviewer, and that sending is a
separate step nothing here can perform, because demo mode built no sinks.

Sixty seconds.

## 4:30 — The numbers, and the ones that are absent

In the terminal:

    make eval-fairness

Point at the three blocks. Say: *the same four CVs under six names and
pronouns, blind mode off and on, and a control that runs each CV three times
with nothing changed. The code will not print the flip rate without the
control beside it. Every figure carries its n and its interval, and the
interpretation line is generated by the code, not written by me.*

Then, without opening anything, say what is not here: no recruiter baseline,
so no productivity number; no priced provider, so no cost table; every figure
from a deterministic stand-in, so nothing about a model's judgement. Point at
`LIMITATIONS.md`.

Thirty seconds.

## If something goes wrong

- **The interface will not start.** `make doctor`. A red line says what.
- **The queue is empty.** `make seed` again; it is idempotent.
- **A page errors.** Reload; state is in the database, not the page. If it
  persists, the terminal running `make demo` has the traceback.
- **You are asked about the model.** It is the deterministic stand-in. Say so,
  say what that means for the numbers, and say the same commands run against a
  real provider with `MODEL_PROVIDER` set.

## What the demo does not show

Delivery (nothing is sent in demo mode), the routing cost table (unpriced), and
calibration (off, with the ablation that showed nothing). Each is a sentence in
the last thirty seconds, not a slide.
